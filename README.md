# Telegram-бот для задач

Учебный проект на Python, aiogram 3 и SQLite3. Команды работают в личном чате с ботом. Каждый пользователь видит и выгружает только свои задачи.

Документация библиотеки: https://docs.aiogram.dev/uk-ua/latest/

## 1. Создай бота

1. Открой https://t.me/BotFather в Telegram и отправь `/newbot`.
2. Выбери название и уникальное имя, заканчивающееся на `bot`.
3. Скопируй полученный API-токен. Не публикуй его и не включай `.env` в архив для сдачи.

## 2. Подготовь окружение

Открой PowerShell в папке проекта. Нужен Python 3.10 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

В `.env` замени `PASTE_YOUR_TOKEN_HERE` на токен от BotFather, сохрани файл.

Если прямое соединение с Telegram зависает, можно указать `BOT_PROXY` в `.env`.
Для проверенной локальной настройки Happ: `BOT_PROXY=http://127.0.0.1:10809`.
Happ должен оставаться включённым. На другом компьютере адрес и порт могут отличаться;
оставь `BOT_PROXY` пустым, если прокси не нужен. После изменения `.env` перезапусти бота.

## 3. Запусти бота

```powershell
.\.venv\Scripts\python.exe bot.py
```

Держи терминал открытым, пока пользуешься ботом. Остановка — `Ctrl+C`. Для повторного запуска выполни ту же команду. Один токен должен использоваться только одним запущенным экземпляром бота.

Открой своего бота в Telegram и отправь:

```text
/start
/add Купить молоко
/add Пройти урок по Python
/add Подготовить домашнее задание
/list
/list_csv
```

## Проверка перед сдачей

1. Проверь подсказку при `/add` без текста.
2. Добавь три задачи и проверь порядок в `/list`.
3. Останови бота, запусти снова и отправь `/list`: задачи должны сохраниться.
4. Отправь `/list_csv`, скачай документ и открой его в Excel или LibreOffice. При ручном импорте выбери UTF-8 и разделитель `;`.
5. В CSV уже добавлены колонки «Статус» и «Категория». Измени их в табличном редакторе и сохрани файл. Это эксперимент с экспортом: обратная загрузка CSV в бота не реализована, следующие выгрузки снова содержат значения «Новая» и «Без категории».
6. При возможности открой бота со второго аккаунта: чужие задачи не должны отображаться.
7. Сделай скриншоты добавления задачи, списка задач и полученного CSV. При необходимости приложи скриншот открытой таблицы.

Время создания хранится в UTC. Номера задач общие для всей базы и могут идти с пропусками в списке отдельного пользователя.

## Что находится в проекте

- `bot.py` — обработчики команд и запуск; назначение функций описано в docstring.
- `database.py` — создание таблицы `tasks (id, text, user, created_at)`, сохранение и чтение задач. SQL-параметры передаются отдельно от текста запроса.
- `export_csv.py` — CSV в UTF-8 с BOM для кириллицы, с дополнительными колонками для эксперимента.
- `tasks.db` — создаётся автоматически рядом с кодом; удаление этого файла удалит сохранённые задачи.
- `test_project.py` — локальная проверка сохранения, порядка, разделения пользователей и формата CSV без подключения к Telegram.

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

Для сдачи приложи исходники, `requirements.txt`, `.env.example`, этот README и скриншоты. Не включай `.env`, `.venv`, `__pycache__` и личную базу `tasks.db`. Живую работу бота проверяют отдельно в Telegram; локальные тесты не подтверждают подключение к Telegram или открытие файла в установленном Excel.
